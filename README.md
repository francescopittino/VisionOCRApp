# VisionOCRApp
Simple App that uses LLM Vision models from Openrouter to extract readable text from an image. Learning Project

## Requires streamlit, openai libraries

## Write your API key in cred.json

## Run with: 

'''shell
streamlit run main.py
'''

## Usage:

**Simply load an image and press the button.
You can choose your output format between plain text, markdown or json.**
